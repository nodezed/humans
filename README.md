# Nodezed Humans (`humans`)

The dedicated engineering showcase, creators platform, and philosophy of the builders behind Nodezed.

## Tech Stack
- Next.js (App Router)
- React 19
- Tailwind CSS v4

## Development
```bash
pnpm install
pnpm dev
```

## Production
Served at [https://humans.nodezed.com](https://humans.nodezed.com) and [https://nodezed.com/humans](https://nodezed.com/humans).
