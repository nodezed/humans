## 🌟 Overview

The **`humans`** application is a dedicated, ultra-lightweight showcase for the engineers and creators behind Nodezed. It operates with zero baggage: no database connections, no cloud drivers, and no auth state.

- **Team Showcase**: Profiles of systems architects, network engineers, and developer experience creators.
- **Engineering Manifesto**: Our core principles on zero egress fees, bare metal speed, and radical transparency.
- **Founders Direct Channel**: An open callout for kernel hackers and distributed systems builders.
- **Canonical Address**: Hosted canonically at `https://nodezed.com/humans` with `basePath: "/humans"`.

## 🛠️ Getting Started

### Prerequisites
- Node.js 20+
- [pnpm](https://pnpm.io/) 10+

### Installation & Development

```bash
# Install dependencies
pnpm install

# Start development server on port 3001
pnpm dev
```

The application will be live at [http://localhost:3001/humans](http://localhost:3001/humans).

### Build & Production

```bash
# Typecheck
pnpm typecheck

# Production build
pnpm build

# Start production server
pnpm start
```
