# Nodezed Humans (`humans`)

The dedicated engineering showcase, creators platform, and philosophy of the builders behind Nodezed.

## Tech Stack
- Next.js (App Router)
- React 19
- Tailwind CSS v4

## Development
```bash
pnpm install
pnpm dev # runs on http://localhost:3001/humans
```

## Production
Served at [https://nodezed.com/humans](https://nodezed.com/humans).
